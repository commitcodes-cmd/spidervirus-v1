# SpiderVirus V1
spiderVirus V1 is a Repository that lets you make your own termux Decorative.
# Installation and Getting Started
Installation is a part where we can make the terminal decorative and cool.
# Termux
- `termux-setup-storage`
- `pkg install git`
- `pkg install python`
- `git clone [url]`
- `cd /sdcard/`
quick interruption:
you need to move the GitHub Repository to Documents in case it's easier to activate
- `cd Documents/url/main.py`
- `python main.py`
- `echo -e "clear\npython /sdcard/Documents/url/main.py" > ~/.bashrc`
to go back. use:
<br>
`> ~/.bashrc
